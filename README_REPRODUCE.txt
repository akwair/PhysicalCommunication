energy, bit counts, noise estimates and/or diagnostics, not complete raw

NMSE is a ratio of summed energies, not a mean of individual ratios. Positive
CP comparison gain favors CP. VALSE contrast signs are separately labeled.

Environment
Use a Python environment matching requirements.txt. No MATLAB, GPU, training
dataset or external service is required to execute the Python experiments.
For strict reproduction set OPENBLAS_NUM_THREADS=1, OMP_NUM_THREADS=1 and
MKL_NUM_THREADS=1 before starting Python. VALSE also sets threadpool limits.
Tiny last-bit changes can occur across numerical library/CPU versions.

VALSE provenance and limits
valse_python.py implements the cited paper equations and Heuristic 2; see
valse_implementation_notes.txt. Original MATLAB source was inspected locally
but is excluded from this repository; its URL/hash are retained in provenance.
No original-source license or MATLAB runtime equivalence is claimed. Python
implementation uses the paper's global covariance index, with a documented
source-index compatibility option. Pilot-only results cannot be read as
full-CFR/BER results. All capped iterations are retained in metrics.

Interpretation
The fixed-subspace formulas are standard Gaussian identities specialized to
the declared model. CP cancellation and continuous-delay estimation have
prior literature. The study is an analysis/empirical paper, not proof of a
new estimator's superiority or publication acceptance. Independent CP groups
do not make CP noise independent of the pilot/data noise; coupling is kept.
The waveform is ideal synchronized, unfiltered, block-static CP-OFDM; no
hardware, Doppler, CFO, or coded-throughput claim is made. The additional
EPA/EVA study uses standardized power-delay profiles under this same model.
Pointwise bootstrap intervals are not multiplicity-adjusted. Optimization
checks concern flagged calls and finite budgets, not global optimality.
